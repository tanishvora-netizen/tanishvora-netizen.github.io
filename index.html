Mixture-of-Experts transformer from scratch

  • PyTorch
  • Triton
  • Cloud GPUs

A small (about 6–10M parameter) DeepSeek-MoE-style transformer built from the ground up, with fine-grained experts, a shared expert, and top-k routing. I wrote a custom Triton kernel for the MoE forward pass and benchmarked it against a naive loop and a matched dense baseline, then looked at what each expert learns to specialize in.

View the code on GitHub

Load-balancing experiment

  • Auxiliary lossThe standard penalty that pushes the router toward even expert usage.
  • Aux-loss-free biasDeepSeek-V3's per-expert bias that rebalances routing without a loss term.
  • Expert-choice routingExperts pick their top tokens instead of tokens picking experts.
