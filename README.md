# tanishvora.github.io

Personal website for Tanish Vora, hosted on GitHub Pages.

## Files

- `index.html`: the whole site (styles and scripts are inside this one file)
- `404.html`: shown when someone visits a page that doesn't exist

## Updating the site

Edit `index.html` (or upload a new version) and commit. GitHub Pages republishes within a minute or two.

The Email, LinkedIn, and Resume buttons still use `#` as placeholder links. Search `index.html` for `href="#"` to find them.
